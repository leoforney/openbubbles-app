  ### Architectural Overview                                                                                                                                                                                                                                                           
                                                                                                                                                                                                                                                                                       
  OpenBubbles uses a multi-tier architecture to send and receive iMessages:                                                                                                                                                                                                            
                                                                                                                                                                                                                                                                                       
  • UI & View Controllers: Flutter with GetX (ConversationViewController, MessagesService, and ObjectBox query streams).                                                                                                                                                               
  • Service & Queue Layer: Dart background services (OutgoingQueue, IncomingQueue, ActionHandler, and RustPushBackend).                                                                                                                                                                
  • Core Protocol Engine: A standalone Rust implementation (rustpush) that connects directly to Apple's Push Notification Service (APNs) and Identity Services (IDS) protocol. Currently, communication between Dart and Rust occurs via flutter_rust_bridge (FRB).                    
  • Native Android Host: Kotlin services (APNService.kt) and headless Flutter workers (DartWorker.kt) interfacing with Rust via UniFFI.

  #### Step-by-Step Breakdown:                                                                                                                                                                                                                                                         
                                                                                                                                                                                                                                                                                       
  1. User Taps the Send Button                                                                                                                                                                                                                                                         
      • In SendButton, onPressed fires (or after the send delay timer completes), triggering sendMessage().                                                                                                                                                                            
      • In ConversationTextFieldState.sendMessage:                                                                                                                                                                                                                                     
          • The input text is extracted and inspected.                                                                                                                                                                                                                                 
          • Auto-effects are detected (e.g. "happy birthday" maps to balloons, "pew pew" maps to lasers, "congrats" maps to confetti).                                                                                                                                                 
          • Calls controller.send(...) on the active ConversationViewController.                                                                                                                                                                                                       
          • Clears the text field, dismisses keyboard drafts, and resets typing indicators.                                                                                                                                                                                            
                                                                                                                                                                                                                                                                                       
  2. Optimistic Message Creation & Animation                                                                                                                                                                                                                                           
      • controller.send delegates to sendFunc, which is mounted by SendAnimationState.send.                                                                                                                                                                                            
      • It instantiates a new Message model with isFromMe = true, handleId = 0, attributedBody, effects, and reply thread GUIDs.                                                                                                                                                       
      • It generates a temporary GUID: _message.generateTempGuid() (e.g., temp-a1b2c3d4).                                                                                                                                                                                              
      • Starts an optimistic flight animation (SendAnimation) that flies the bubble into the list.                                                                                                                                                                                     
  3. Queueing & Database Persistence (prepMessage)                                                                                                                                                                                                                                     
      • The message is pushed to the queue:                                                                                                                                                                                                                                            
        outq.queue(OutgoingItem(type: QueueType.sendMessage, chat: controller.chat, message: _message));                                                                                                                                                                               
                                                                                                                                                                                                                                                                                       
      • In Queue.queue, prepItem is called before network processing:                                                                                                                                                                                                                  
          • ActionHandler.prepMessage assigns the temp GUID, inserts the record into ObjectBox via chat.addMessage(message), and updates the chat sort order.                                                                                                                          
          • MessagesService watches the ObjectBox query or updates its in-memory list, rendering the bubble immediately.                                                                                                                                                               
          • At this point, DeliveredIndicator.getText() evaluates message.guid.contains("temp") and displays "Sending..." (or remains blank on iOS mode).                                                                                                                              
                                                                                                                                                                                                                                                                                       
  4. Sending over the Wire via RustPush                                                                                                                                                                                                                                                
      • The queue worker executes OutgoingQueue.handleQueueItem, calling ActionHandler.sendMessage.                                                                                                                                                                                    
      • ActionHandler calls RustPushBackend.sendMessage:                                                                                                                                                                                                                               
          • Parses rich links and message parts.                                                                                                                                                                                                                                       
          • Invokes api.newMsg(...) to construct the raw message structure with the sender handle and chat participants.                                                                                                                                                               
          • Calls sendMsg(msg), which calls api.send(...) via flutter_rust_bridge.                                                                                                                                                                                                     
          • In Rust (rustpush), the packet is serialized, signed, encrypted with the destination device's IDS public keys, and transmitted over an authenticated TLS connection to Apple's APNs/IDS push gateway.                                                                      
                                                                                                                                                                                                                                                                                       
  5. Transition to "Sent"                                                                                                                                                                                                                                                              
      • Once Apple's gateway accepts the payload, RustPushBackend.sendMessage returns the reflected message with its permanent server GUID.                                                                                                                                            
      • ActionHandler.matchMessageWithExisting is called:                                                                                                                                                                                                                              
          • It replaces the temp-xxxx message in ObjectBox with the real GUID via Message.replaceMessage(...).                                                                                                                                                                         
          • It updates MessagesService.                                                                                                                                                                                                                                                
          • The message is no longer "temp". If tapped or inspected, DeliveredIndicator displays "Sent [Time]".                                                                                                                                                                        
                                                                                                                                                                                                                                                                                       
  6. Transition to "Delivered" (and "Read")                                                                                                                                                                                                                                            
      • When the recipient's Apple device receives and unpacks the push message, it sends a signed delivery acknowledgment back to Apple IDS.                                                                                                                                          
      • Apple routes this delivery receipt back to the sender's client session.                                                                                                                                                                                                        
      • Rust receives the incoming receipt packet and passes it to Dart as api.Message_Delivered (containing the message ID and delivery timestamp).                                                                                                                                   
      • In rustpush_service.dart:3684-3714:                                                                                                                                                                                                                                            
          • Finds the message in ObjectBox: var message = Message.findOne(guid: myMsg.id).                                                                                                                                                                                             
          • Sets message.dateDelivered = parseDate(myMsg.sentTimestamp).                                                                                                                                                                                                               
          • Saves to ObjectBox and queues an IncomingItem(type: QueueType.updatedMessage) into inq.                                                                                                                                                                                    
          • Fires eventDispatcher.emit("message-updated-${m.guid}").                                                                                                                                                                                                                   
      • DeliveredIndicator is listening to this event and observes dateDelivered != null.                                                                                                                                                                                              
      • It re-renders, displaying "Delivered" (or "Delivered Quietly" / delivery timestamp depending on user preferences).                                                                                                                                                             
      • When the recipient reads the message, a similar flow occurs with api.Message_Read, updating the indicator to "Read [Time]".

  ### Part 2: Receiving a Message (Across All App States)                                                                                                                                                                                                                              
                                                                                                                                                                                                                                                                                       
  OpenBubbles uses an Android background service (APNService.kt) connected to Rust's NativePushState. When Apple pushes a message to the active socket, Rust triggers the UniFFI callback MsgReceiver.receieved_msg(ptr, retry).

  #### 1. App is CLOSED (Process not running / Engine Dead)                                                                                                                                                                                                                            
                                                                                                                                                                                                                                                                                       
  1. Wake-up via Service: APNService is running in the background or restarted by Android.                                                                                                                                                                                             
  2. UniFFI Callback: Rust invokes APNService.receievedMsg(ptr, retry).                                                                                                                                                                                                                
  3. Headless Engine Creation: Because MainActivity.engine == null, DartWorker.callMethod is invoked.                                                                                                                                                                                  
      • It initializes a headless FlutterEngine (initNewEngine).                                                                                                                                                                                                                       
      • Retrieves the Dart callback handle from SharedPreferences (flutter.backgroundCallbackHandle).                                                                                                                                                                                  
      • Executes the background isolate and waits for Dart to signal ready.                                                                                                                                                                                                            
  4. Channel Invocation: Dispatches the "APNMsg" method channel with {pointer: ptr, retry: retry}.                                                                                                                                                                                     
  5. Processing in Dart:                                                                                                                                                                                                                                                               
      • pushService.recievedMsgPointer waits for Database.waitForInit().                                                                                                                                                                                                               
      • Calls api.ptrToDart(ptr) to convert the memory pointer into a PushMessage object from Rust.                                                                                                                                                                                    
      • Resolves or creates the Chat and saves the incoming Message to ObjectBox.                                                                                                                                                                                                      
      • Calls api.completeMsg(ptr) so Rust marks it delivered and stops retrying.                                                                                                                                                                                                      
  6. Notification Trigger: Because the UI is dead (!ls.isAlive), it invokes MessageHelper.handleNotification(m, c), calling the native notifications API to show a heads-up notification with conversation bubbles.                                                                    
  7. Cleanup: DartWorker starts a 30-second teardown timer; if no further work arrives, the headless FlutterEngine is destroyed to free RAM.                                                                                                                                           
                                                                                                                                                                                                                                                                                       
  #### 2. App is in BACKGROUND (Process alive, Activity paused/stopped)                                                                                                                                                                                                                
                                                                                                                                                                                                                                                                                       
  • MainActivity.engine remains alive in memory.                                                                                                                                                                                                                                       
  • APNService.receievedMsg skips DartWorker and calls MethodCallHandler.invokeMethod("APNMsg", ...) directly on the existing engine.                                                                                                                                                  
  • Message is decrypted, saved to ObjectBox, and marked handled.                                                                                                                                                                                                                      
  • Because the UI lifecycle is in background (ls.isDead or !ls.isAlive), MessageHelper.handleNotification posts a system notification and updates the launcher badge.                                                                                                                 
                                                                                                                                                                                                                                                                                       
  #### 3. App is in FOREGROUND (On Chat List or Settings)                                                                                                                                                                                                                              
                                                                                                                                                                                                                                                                                       
  • The main engine receives the "APNMsg" event.                                                                                                                                                                                                                                       
  • ObjectBox saves the message.                                                                                                                                                                                                                                                       
  • IncomingQueue processes the item.                                                                                                                                                                                                                                                  
  • Since cm.isChatActive(chat.guid) is false:                                                                                                                                                                                                                                         
      • It plays an alert sound or drops an in-app banner.                                                                                                                                                                                                                             
      • Updates the chat's snippet, timestamp, and unread badge.                                                                                                                                                                                                                       
      • Re-sorts the conversation list via chats.updateChat(c, shouldSort: true).                                                                                                                                                                                                      
                                                                                                                                                                                                                                                                                       
                                                                                                                                                                                                                                                                                       
  #### 4. App is FOREGROUND INSIDE Conversation Detail                                                                                                                                                                                                                                 
                                                                                                                                                                                                                                                                                       
  • The user is currently reading the chat (cm.isChatActive(chat.guid) == true).                                                                                                                                                                                                       
  • MessagesService for this chat receives the new message (via the ObjectBox query watcher or ms(chat.guid).addMessage(message)).                                                                                                                                                     
  • The message is inserted directly into the conversation list with incoming animations and an in-app message tone.                                                                                                                                                                   
  • System Notification Suppressed: Chat.addMessage recognizes the chat is active and clears/suppresses local notification alerts.                                                                                                                                                     
  • Automatic Read Receipt: Chat.addMessage executes toggleHasUnread(false, privateMark: true). This invokes backend.markRead(chat, true), causing RustPush to immediately generate and transmit an api.Message.read() packet over Apple IDS to mark the message as read for the sender.

  ### Part 3: Transitioning the Service System to Native Android (Kotlin + Rust)

  #### 1. Unify Rust under UniFFI (Deprecate flutter_rust_bridge)                                                                                                                                                                                                                      
                                                                                                                                                                                                                                                                                       
  • Current State: A split-brain setup where Dart uses flutter_rust_bridge (api.rs) while Kotlin uses UniFFI (native.rs).                                                                                                                                                              
  • Action:                                                                                                                                                                                                                                                                            
      • Remove flutter_rust_bridge dependencies and generated files.                                                                                                                                                                                                                   
      • Expose all core services through UniFFI in rust/src/native.rs:                                                                                                                                                                                                                 
          • send_message(conversation_data, message_parts, reply_guid, effect, ...)                                                                                                                                                                                                    
          • send_read_receipt(conversation_data, last_message_guid)                                                                                                                                                                                                                    
          • send_typing_indicator(conversation_data, is_typing)                                                                                                                                                                                                                        
          • download_attachment(attachment_data, destination_path, progress_callback)                                                                                                                                                                                                  
          • upload_attachment(source_path, mime_type, progress_callback)                                                                                                                                                                                                               
          • parse_ptr(ptr) returning a clean, UniFFI-serializable PushMessage Kotlin record.                                                                                                                                                                                           
                                                                                                                                                                                                                                                                                       
                                                                                                                                                                                                                                                                                       
  
  #### 2. Native Data Layer (ObjectBox Kotlin)
  
  • Current State: Dart uses ObjectBox Dart (models.dart). Kotlin already has entity definitions started in com.bluebubbles.messaging.objectbox.* (ChatEntity, MessageEntity, AttachmentEntity).
  • Action:
      • Make native ObjectBox the sole source of truth.
      • Ensure all database migrations, indices (GUID index), and relations (ToOne<ChatEntity>, ToMany<AttachmentEntity>) are configured in Kotlin.
      • Expose queries as reactive Kotlin Coroutine Flows (box.query().watch().flow()) to bind directly into Jetpack Compose screens.
  

  #### 3. Native Outgoing Pipeline (Replacing OutgoingQueue & ActionHandler)
  
  • Current State: MessageSender.kt saves to ObjectBox, then calls DartWorker.callMethod("execute-rust-send") to delegate sending back to Dart.
  • Action:
      • Eliminate the Dart callback entirely.
      • Create a native OutgoingMessageManager:
          1. Optimistic Insert: Save MessageEntity with temp-... GUID and status SENDING to ObjectBox. Compose UI updates instantaneously.
          2. Attachment Upload: If attachments exist, invoke the Rust UniFFI upload function; save resulting metadata to AttachmentEntity.
          3. Rust Transmission: Call UniFFI send_message(...) from a Kotlin coroutine on Dispatchers.IO.
          4. Offline / Resilience: Use Android WorkManager (SendMessageWorker) with network constraints so messages queued while offline or during app exit send reliably without relying on UI presence.
          5. Guid Reconciliation: On send success, update the message GUID in ObjectBox from temp-... to the server GUID and set status to SENT. On failure, update errorVal and post a notification.
  


  #### 4. Native Incoming Pipeline (Replacing IncomingQueue & DartWorker)
  
  • Current State: APNService spawns a headless FlutterEngine through DartWorker to process incoming packets.
  • Action:
      • Delete DartWorker.kt entirely.
      • In APNService.kt:receievedMsg:
          1. Parse the pointer directly using Rust UniFFI: val pushMsg = RustPush.getAndAcknowledgeMessage(ptr).
          2. If it is a delivery receipt (Message_Delivered):
              • Find MessageEntity in ObjectBox by GUID:
                val msg = messageBox.query(MessageEntity_.guid.equal(pushMsg.guid)).build().findFirst()
                msg?.dateDelivered = Date(pushMsg.timestamp)
                messageBox.put(msg)
  
              • The Compose UI watching that message auto-updates to "Delivered".
          3. If it is a new message:
              • Insert the MessageEntity and AttachmentEntity into ObjectBox.
              • Acknowledge to Rust (RustPush.completeMsg(ptr)).
              • Check active chat state:
                  • If active in ChatScreen: Play in-app sound, emit read receipt via Rust (RustPush.sendReadReceipt(...)), and suppress system notifications.
                  • If closed/background: Use Android's NotificationManagerCompat + ShortcutManagerCompat + Person to dispatch an Android 11+ Conversation Notification / Bubble.
  




  #### 5. Native Background Service Management
  
  • Android 14+ enforces strict Foreground Service Types.
  • Ensure APNService is registered in AndroidManifest.xml with:
    android:foregroundServiceType="remoteMessaging|dataSync"
  
  • Implement ConnectivityManager.NetworkCallback in Kotlin to trigger Rust connection reconnects upon network changes (e.g. WiFi <-> Cellular).
